Kaval Arann: Public–Police Communication & Incident Reporting Platform

Aug 2020 - Jul 2021 • 7 min read • Android / Kotlin Node.js / Express Room DB Retrofit CameraX & Geolocation Jetpack Navigation • Official Mention

Kaval Arann is a real-world civic technology platform developed as a group project by a 10-member team for Tiruchirappalli City Police to enable citizens to report incidents and police personnel to ingest, manage, and resolve them in real-time. Built as a dual-app system — a citizen-facing incident reporting application and a police-facing incident management dashboard — both are deployed in production and in active use across Tiruchirappalli.

Architectural Overview & Core Innovations

Designing a platform for public safety requires balancing two vastly different operational profiles: citizens reporting emergencies or property theft under low-connectivity or high-stress conditions, and police officers managing high-volume operational queues with strict role-based triage requirements.

Single-Codebase, Multi-Flavor Architecture (40% Development Effort Reduction)

To prevent codebase duplication between the Citizen and Police applications, I engineered a single-codebase, multi-flavor Android architecture leveraging Gradle product flavors and flavor-specific source sets:

  • Shared Core Layer: Unified domain models, Retrofit REST API client, Room database layer, repository implementations, and base MVVM ViewModels.
  • Flavor-Specific Layers: Independent UI fragment graphs, permission handlers, notification channels, and flavor-specific resource assets (icons, strings, themes).
  • Impact: Achieved a 40% reduction in duplicate development effort and long-term maintenance overhead. Bug fixes and core data layer enhancements propagate automatically to both applications.

Single-Activity Jetpack Navigation (15+ Screens, Type-Safe)

Implemented a modern single-activity, multi-fragment architecture utilizing the Android Jetpack Navigation Component:

  • Utilized Safe Args plugin for compile-time type-safe argument passing between incident creation workflows and detail views.
  • Scoped ViewModels to navigation graph lifecycles, enabling multi-step report creation wizards to retain state safely across configuration changes.
  • Reduced navigation-related runtime crashes to near-zero across 15+ screens.

End-to-End Incident & Theft Reporting Pipeline

Built robust citizen reporting modules for property loss, vehicle theft, and locked-house notifications:

  • Structured Data & Evidence Capture: Integrated CameraX with custom image/video compression and timestamp/location watermarking to ensure evidence integrity.
  • Precision Geolocation: Used FusedLocationProviderClient + reverse geocoding to capture exact GPS coordinates for incident mapping.
  • Police Triage Dashboard: Created real-time report listing, sorting, and status transition workflows using RecyclerView diffing and MVVM LiveData/Flow observers.

Offline-First Resilience with Room & Repository Pattern

In low-connectivity civic reporting scenarios, users cannot afford to lose draft reports. I implemented an offline-first persistence layer:

  • All draft reports are immediately written to an offline Room database before attempting network transmission.
  • A background sync worker monitors network state via ConnectivityManager and automatically flushes queued reports to the Node.js backend when connection is restored.
  • Conflict resolution handles server-side status updates without overwriting un-synced local edits.

Key Feature Modules

Citizen Application

  • Vehicle & Mobile Theft Reporting: Structured forms with mandatory IMEI / vehicle identification validation.
  • Locked-House Alerts: Citizens notify local police precincts when leaving home unattended for extended periods to prioritize patrol routes.
  • CCTNS Integration Endpoint: Linked with national police-networking guidelines for standardized data ingestion.
  • Directory & Emergency Contacts: One-tap access to local precinct stations and helpline numbers.

Police Administration Application

  • Operational Workflows: Real-time status management (Pending, Under Investigation, Resolved).
  • Locked-House Patrol Map: Visual precinct monitoring of active locked-house alerts.
  • Public Request Triage: Immediate filtering by category, urgency, and precinct boundary.

Deployment & Real-World Impact

  • Deployment Target: Tiruchirappalli City Police Department + citizen population across Tiruchirappalli, Tamil Nadu.
  • Production Status: Live and in active operational deployment.
  • Institutional Recognition: Documented in official NIT Trichy Delta Force institutional report (Delta Force PDF, Page 2).
